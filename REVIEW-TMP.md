Define `context` in glossary and in the README.md file

> In the world of Large Language Models (LLMs) and agentic coding, context is the complete set of text, data, instructions, tool definitions, and memory passed into the model at inference time.
> Because an LLM's pre-trained weights are static and cannot be updated on the fly, context is the active "working memory" that tells the model what the project is, what code is in front of it, what tools it can call, and what it just did
